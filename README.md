# Google Maps & Kadaster BAG Studio

Een standalone webapplicatie voor adres-autocomplete, geocoding en woninginrichter domeinmodel analyse (Niveau 1 Gebouw & Niveau 2 Object).

## 🚀 Live Demo
- **GitHub Pages:** [https://gj915427.github.io/google-maps-studio/](https://gj915427.github.io/google-maps-studio/)

## 🏗️ Functionaliteiten
1. **Hybride Autocomplete:** Razendsnelle Nederlandse adressen via PDOK Locatieserver (Kadaster BAG) + Google Places.
2. **Interactieve Kaartpin:** Verplaatsbare kaart met vaste speld (Airbnb-stijl).
3. **Woninginrichter Domeinmodel:**
   - **Niveau 1: Gebouw (Pand):** Pand-ID, bouwjaar, aantal verblijfsobjecten, parkeersituatie, toegang casco en Street View gevelbeeld.
   - **Niveau 2: Object (Wooneenheid):** VBO-ID, gebruiksoppervlakte m², gebruiksdoel, etage, lift met rollen-geschiktheid.
4. **Automatische Classificaties:** Sjouw-risicoscore voor monteurs en ondervloerconditie (houten balklaag vs vloerverwarming).
